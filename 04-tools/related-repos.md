# Related Repos & Tools

## Core documentation
- **Mailo037/catweb-docs** — structured CatDocs, UIGPT, JSONScript, Assets, AI skill, web runner, validator  
  https://github.com/Mailo037/catweb-docs
- **Mailo037/catweb-additional-resources** — community drop-box of ready-to-import JSONs / full sites  
  https://github.com/Mailo037/catweb-additional-resources
- **Mailo037/catweb-mcp** — MCP server so agents can search the docs + templates by tag/author  
  https://github.com/Mailo037/catweb-mcp

- **SwirX/catpile** — Pythonic DSL → CatWeb JSON (script + UI)  
  https://github.com/swirx/catpile
- **artofcoding212/CatWebScript** — text language that compiles to CatWeb blocks  
  https://github.com/artofcoding212/CatWebScript
- **thecreare/CatWebCompiler** — another text → JSON compiler
