# Local / System Pages (`catweb://`)

These are built-in pages that live inside the CatWeb browser itself.  
Type them in the address bar or link to them with `TextButton?link` / `Redirect to`.

| URL | What it does |
|-----|--------------|
| `catweb://newtab` | Opens a new tab (default landing) |
| `catweb://newtab-incognito` | Opens a new tab (incognito variant) |
| `catweb://domains` | Your owned domains / “Your Websites” |
| `catweb://domains/welcome` | New-player domain choice screen |
| `catweb://settings` | Appearance, Accessibility, Cookies, Chat, Keybinds, About |
| `catweb://version` | Current CatWeb version |
| `catweb://whats-new` | Latest update changelog |
| `catweb://catweb-urls` | List of all system sites |
| `catweb://discover` | Sites from players currently online in the server |
| `catweb://flags` | Experimental flags / experiments |
| `catweb://network-errors` | Network error examples (e.g. 404) |
| `catweb://crash` | Crash-related error pages |
| `catweb://textchatservice` | Broadcast policy notice |
| `catweb://credits` | Translators + open-source module credits |
| `catweb://premium` | Premium gamepass info page |

### Settings breakdown (`catweb://settings`)

- **Appearance** — 18 preset themes + custom themes (Premium)
- **Accessibility** — high contrast, etc.
- **Cookies** — related to the Cookies gamepass
- **Chat** — show/hide chat tags
- **Keybinds** — browser-style shortcuts (Ctrl+T new tab, Ctrl+L address bar, Ctrl+Tab, etc.)
- **About** — links to What’s New, Rules, Credits
